# SpectraFall Puzzle — Godot 4 (Android)

Colorful chain-reaction match-3 game. Free to play, works offline.

## Features
- Match 3+ colored blocks to clear them
- Chain reactions with multiplier scoring
- Combo meter that charges and launches fireballs
- Fireballs can trigger further chain reactions
- Portrait 720x1280, mobile-first touch controls

## Tech
- Godot 4.6 (GDScript)
- Android export (arm64-v8a + armeabi-v7a)
- AdMob banner / interstitial / rewarded

## Build
```bash
./build_spectrafall.sh <versionCode> <versionName>
```
